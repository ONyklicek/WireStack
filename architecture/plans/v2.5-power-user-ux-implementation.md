## SV — Saved views + column/filter presets (v1-gaps #6) 🟢 nejlepší hodnota/úsilí

### Proč nízké úsilí
Table state je **už** kompletně serializovatelný (`StateContainer` →
`StateSerializer`) a **už** se enkóduje do URL (`TableUrl`). Saved view = **uložit
tentýž state blob do DB per-user + obnovit + UI**. Žádný nový state model.

### Práce
| Krok | Soubor | Změna |
|---|---|---|
| SV-1 | `table/src/SavedViews/SavedView.php` + migrace | Eloquent model (`user_id`, `table_key`, `name`, `state` JSON, `is_shared`, `is_default`) |
| SV-2 | `table/src/SavedViews/SavedViewManager.php` | `save(name, StateContainer)` / `apply(SavedView)` / `list(tableKey, user)`; serializace přes existující `StateSerializer` |
| SV-3 | `WithTable` (tenký hook) | `saveCurrentView($name)` / `applyView($id)` / default view na mount; deleguje na manager (po V2.1 do collaboratoru) |
| SV-4 | Blade — view switcher dropdown | seznam uložených pohledů + „uložit aktuální" + default toggle; floating dropdown (existující `wireDropdown`) |
| SV-5 | presets = podmnožina | column preset = view jen s `columns.hidden`; filter preset = view jen s `filters` — stejný model, jiný scope uloženého blobu |

### Sdílení & scope
- `is_shared` → viditelné celému týmu; jinak per-user.
- **Tenancy (V2.4):** saved views scopnuté na tenanta (tenant + user).
- **Authorization:** sdílený view respektuje `HasAuthorization` (kdo smí sdílet).

### Testy
Save/apply round-trip (state blob = identický po restore); default view na mount;
per-user izolace; shared view viditelný; column/filter preset jako partial state;
tenant scope (V2.4 interakce).

## GS — Global search (⌘K) — závisí na V2.3

### Cíl
Command-palette hledání napříč **resources** (CRM/CMS/SaaS standard). „Resource" =
V2.3 `ResourceRegistry` → GS iteruje registrované resources a jejich searchable
sloupce.

### Práce
| Krok | Soubor | Změna |
|---|---|---|
| GS-1 | `core/src/GlobalSearch/GlobalSearchProvider.php` | per-resource: `getGloballySearchable(): array`, `search($term): results` (title/subtitle/url/icon) |
| GS-2 | `Resource` (V2.3) | `globalSearch()` opt-in — které sloupce, jak zobrazit výsledek; delegace na `DataSource` search (V2.0) |
| GS-3 | `core/src/GlobalSearch/GlobalSearchCenter.php` + Blade | ⌘K Livewire komponenta (debounce, teleport modal, keyboard nav); mirror `NotificationCenter` (V2.4) vzor |
| GS-4 | scope/authorization | výsledky respektují policy + tenant scope (V2.4) — **neukázat, co uživatel nesmí vidět** |

### Závislost
**Hard-dep na V2.3** (ResourceRegistry) — bez owner vrstvy není „resource" k
prohledání. GS proto až po V2.3.

**A hard-dep na rozhodnutí, kde ten registr žije.** GS-1 a GS-3 jsou plánované do
`core/src/`, zatímco `v2.3` ukládá `ResourceRegistry` do `packages/table`. Core na
table nevidí a vidět nesmí. Než se GS začne psát, musí být rozhodnuto podle
poznámky v [`v2.3-owner-layer-implementation.md`](v2.3-owner-layer-implementation.md)
§ R.2 — jinak GS-1 ten cyklus vytvoří.

### Testy
Search napříč resources; policy filtr (skryté resources/records se neukážou);
tenant scope; keyboard nav; debounce; `DataSource` search delegace.

## LT — Large-table UX (v1-gaps #8)

### Cíl
Datově těžké ERP seznamy — grouping už hotový, chybí virtuální scroll (+ volitelně
advanced filter builder).

### Práce
| Krok | Soubor | Změna |
|---|---|---|
| LT-1 | `table/resources/js/` + index.blade | **virtual scrolling** — Alpine + IntersectionObserver windowing; renderuje jen viditelné řádky; kompatibilní s existující pagination (mode `virtual` vedle simple/cursor) |
| LT-2 | `WithTable`/`TableDataset` (V2.1) | `virtual` paginační mode → chunk fetch on-scroll (staví na `DataSource::paginate` cursor); po V2.1 do `TableDataset` |
| LT-3 | grouping polish (volitelné) | collapse/expand skupin (staví na hotovém `HasGrouping` + existující `rows.expanded`) |
| LT-4 | advanced filter builder (**stretch, volitelné**) | AND/OR kombinátor nad existujícími filtry; samostatná featura — **jen když bude prostor** |

### Riziko
Virtual scroll × existující features (selection all, sub-rows, sticky header,
sortable) — musí koexistovat. Mitigace: `virtual` je opt-in mode, ne default;
konfliktní kombinace (virtual + sub-rows) explicitně zakázat/degradovat.

### Testy
Virtuální scroll renderuje jen viewport; chunk fetch on-scroll (cursor);
kompatibilita se selection/sort; `virtual` mode opt-in; degradace u konfliktů.

## Testovací strategie

- **SV:** state round-trip identita (serialize→persist→restore = stejný blob);
  per-user/shared/tenant izolace; presets jako partial state.
- **GS (security-aware):** policy + tenant filtr povinný (leak test); keyboard nav;
  `DataSource` search delegace.
- **LT:** viewport-only render; chunk fetch; opt-in mode; konflikt degradace.
- **Matrix:** `composer test:table` (SV/LT) + `test:core` (GS) + `Integration`
  (state persist, resource search); `analyse`+`lint`; benchmark (virtual scroll
  na 100k+ řádcích = hlavní perf důkaz LT).

## Rizika & mitigace

| Riziko | Mitigace |
|---|---|
| GS ukáže zakázaná data (leak) | policy + tenant scope na výsledcích **povinné**; leak test = gate |
| Virtual scroll rozbije selection/sub-rows | opt-in mode; konfliktní kombinace zakázat/degradovat |
| Saved view blob nekompatibilní po změně schématu state | verzovat blob; při mismatch fallback na default (ne crash) |
| GS bez V2.3 nemá „resource" | hard-dep V2.3; do té doby neplánovat |
| LT-4 scope creep | advanced filter builder = **stretch**, jen při prostoru |
