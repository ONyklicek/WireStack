# V2.1 — Rozřezání monolitů: implementační plán

Rozpracování fáze **V2.1** z [`v2-master-plan.md`](v2-master-plan.md). Cíl:
`WithTable` → headless collaborators + tenký Livewire adapter (ADR 0017
invariant C), `Column` base zmenšit + specializované typy (invariant D). Bez
změny public API.

## 0. Korekce scope (ověřeno v kódu 2026-07-06)

Původní V2.1 scope (z v2-deferred #5/#6) je **částečně už hotový** — plánujeme jen
reálný zbytek:

| Položka | Původní plán | **Skutečný stav** | V2.1 akce |
|---|---|---|---|
| **Modal shell → komponenta** (#6) | „~600 ř. inline v index.blade" | **HOTOVO** — `partials/action-modal.blade` + `halt-modal` už používají kanonické `<x-wire-modals::slide-over>`/`modal` z wire-core | jen ověřit + smazat z plánu |
| **Filter views → form fields** (#5) | „5 custom views" | **Z VELKÉ ČÁSTI HOTOVO** — `Filter` base + `DateFilter` + `NumberRangeFilter` jedou přes `tables.filters.form-field`; custom zůstává jen `SelectFilter` (searchable dropdown) + `TernaryFilter` | reziduum: zvážit form-field i pro Select/Ternary (oprávněně custom → **nechat**, jen zdokumentovat) |
| **WithTable split** | monolit | **REÁLNÉ** — 3213 ř., 96 public metod, 435 couplingů na `tableState`/`dispatch`/`$this` | 🔴 hlavní práce |
| **Column shrink + typy** | „god object 1717 ř." | base už deleguje concerns do Foundation traitů (`HasColor/HasIcon/HasSize/HasFontWeight/HasResponsive/HasSummary/HasView/HasAuthorization`, extends `DataComponent`); pořád 1749 ř. / 139 metod; **chybí** Money/Status/Relation/Metric typy | reálné, skromnější |

**Závěr:** V2.1 = **(A) rozřezání `WithTable`** (těžiště) + **(B) zmenšení `Column`
base a doplnění specializovaných typů**. #5/#6 jsou mimo (hotové).

## A. Rozřezání `WithTable` na headless collaborators

### A.1 Současný stav

`WithTable` je Livewire trait mixující 96 public metod a ~15 dalších traitů
(`TableQueryService`, `HasGrouping`, `HasSubRows`, `HasSummary`, `HasResponsive`,
`HasView`, `WithTableQueryString`, forms `InteractsWith*`). Traity **nejsou
headless** — sahají na `$this->tableState`, `$this->dispatch()`, Livewire
lifecycle. 435 takových couplingů.

### A.2 Cílové collaborators (plain PHP, testovatelné bez Livewire)

Dle ADR 0017 invariant C (dataset · state · selection/bulk · render · Livewire adapter):

| Collaborator | Vlastní | Pohltí z WithTable | Vazba na jinou fázi |
|---|---|---|---|
| **`TableDataset`** | query build + paginate + cache + change-token | `TableQueryService`, `paginateQuery`, `executeWithCache`, `generateQueryCacheKey`, `get/count` | **sem přistane V2.0 `DataSource`** |
| **`TableSelection`** | výběr řádků + resolve bulk/single record | `toggleRecordSelection`, `selectAllRecords`, `getSelectedRecords`, resolve `find/whereIn` | **sem přistane V2.0.b `RecordContract`** |
| **`TableActionRunner`** | action pipeline (table/bulk/header/confirmed) + modal flow | `executeTableAction*`, `executeBulkAction*`, `executeHeaderAction*`, `executeConfirmedAction` | delegace na core `ActionPipeline` |
| **`TableRenderState`** | render-data (rows→viewdata, viditelnost sloupců, sub-rows, summary, flatten, expansion) | `HasSubRows`, `HasSummary`, `HasGrouping` render části, `toggleColumn`, `toggleRowExpansion`, `toggleFlattenMode` | — |
| **`WithTable` (adapter)** | Livewire lifecycle + `tableState` (serialized) + delegace | `mount*`, `updated*`, `render`, polling, thin wrappery public metod | drží Livewire coupling |

**Vzor:** strangler-fig. Public API `WithTable` (96 metod) zůstává **beze změny** —
tělo se přesune do collaboratoru, metoda se stane tenkou delegací. Každá extrakce
je samostatně zelená.

### A.3 Pořadí extrakce (nízké riziko → vyšší)

| Krok | Collaborator | Proč pořadí | Odhad |
|---|---|---|---|
| A-1 | `TableDataset` | nejčistší seam (query už je v `TableQueryService`); **nosič V2.0.a** | 3–4 d |
| A-2 | `TableSelection` | malý, izolovaný; **nosič V2.0.b `RecordContract`** | 2 d |
| A-3 | `TableRenderState` | střední; render-data bez side-effectů | 3 d |
| A-4 | `TableActionRunner` | největší blast radius (modal flow, forms integrace) — až po ustálení | 4 d |
| A-5 | `WithTable` adapter dočistit | tenký lifecycle + delegace; smazat pohlcené traity | 2 d |

**Coupling strategie:** collaborator dostane stav přes konstruktor/DTO
(`TableStateView` read-model nad `tableState`), **nesahá** na Livewire `$this`.
Side-effekty (dispatch, notifikace) vrací jako výsledek/`ActionResult`, adapter je
provede. Tím se collaborator testuje bez Livewire lifecyclu (ADR 0017 exit).

### A.4 PHPStan gotcha (kritické)

`WithTable` je dnes analyzovaný **jen jako trait** (konkrétní hosti jsou v
`excludePaths`, viz `RelationManager` gotcha [[filament_parity]]). Nové
collaborators jsou **konkrétní třídy** → PHPStan je bude analyzovat naostro. To je
**žádoucí** (proto extrakce), ale: collaborators nesmí dědit Livewire magii →
musí být čisté PHP, jinak explodují stejně jako `WithTable`. Toto je hlavní důvod,
proč jsou headless.

## B. Zmenšení `Column` base + specializované typy

### B.1 Současný stav

`Column` (1749 ř., 139 public metod) extends `DataComponent`, deleguje design
concerns do Foundation traitů. **Není** to duplicitní god-object — ale base pořád
absorbuje surface-specific chování, které dle invariant D patří do typů.
Specializované typy dnes: Text/Badge/Boolean/Icon/Image/Select/Toggle/Button
(474 ř.)/Poll (630 ř.)/Stacked (385 ř.)/Split/TextInput (823 ř.). **Chybí** cílové
ERP typy: `MoneyColumn`, `StatusColumn`, `RelationColumn`, `MetricColumn`.

### B.2 Práce

| Krok | Obsah | Odhad |
|---|---|---|
| B-1 | **Audit 139 metod base**: rozdělit na *cross-cutting* (identity, visibility, capabilities, state format, view resolve — zůstává) vs *surface-specific* (patří do typu). Výstup: seznam metod k přesunu. | 1 d |
| B-2 | `StatusColumn extends BadgeColumn` (ADR 0018 — enum status → barva/ikona přes `Enum\HasColor/HasLabel/HasIcon`) | 1 d |
| B-3 | `MoneyColumn` (měna/formát/lokalizace nad `FormatsState`) | 1 d |
| B-4 | `RelationColumn` (auto eager-load relace; konsoliduje dnešní `->relationship()` roztroušené v base) | 1–2 d |
| B-5 | `MetricColumn` (agregace/sparkline nad existující summary infrastrukturou) | 1 d |
| B-6 | Přesun surface metod z base do typů + `@deprecated` na base variantách (odstranění 3.0) | 2 d |

**BC:** `Column::make()` a všechny stávající typy fungují beze změny; nové typy
jsou aditivní; přesuny z base jsou deprecation-first (base metoda deleguje na typ
přes shim celý 2.x).

## C. Reziduum #5/#6 (mimo hlavní práci)

- **Modal:** ověřit, že `action-modal`/`halt-modal` partial nemají žádnou zbytkovou
  bespoke modal logiku mimo `<x-wire-modals::*>`; pokud ano, doladit. **Jinak
  nedělat nic** — je hotové. (½ d ověření.)
- **Filtry:** `SelectFilter` (searchable dropdown) a `TernaryFilter` mají
  oprávněně custom view. Rozhodnutí: **nechat custom**, zdokumentovat proč (ne
  každý filtr je form-field). (½ d docs.)

## Roadmap (sekvence / závislost / riziko / odhad)

| Krok | Obsah | Závislost | Riziko | Odhad |
|---|---|---|---|---|
| **A-1** | `TableDataset` (+ V2.0.a) | V2.0.a hotové/paralelně | střední | 3–4 d |
| **A-2** | `TableSelection` (+ V2.0.b RecordContract) | A-1 | vysoké (blast radius) | 2 d |
| **A-3** | `TableRenderState` | A-1 | střední | 3 d |
| **A-4** | `TableActionRunner` | A-2, A-3 | vysoké (modal/forms) | 4 d |
| **A-5** | `WithTable` adapter dočistit | A-1..A-4 | nízké | 2 d |
| **B-1..6** | Column shrink + typy | nezávislé na A (paralelizovatelné) | nízké–stř. | 7–8 d |
| **C** | reziduum #5/#6 | — | nízké | 1 d |

**Celkem ~24–26 dní** čistého času. A (WithTable) a B (Column) jsou
**paralelizovatelné** (různé soubory) — při dvou lidech ~2–3 týdny.

### Milníky & kritická cesta

```
V2.0.a hotové ──► M1: TableDataset zelený (A-1)  ← V2.0 read-cesta zapojena
                     │  stávající table suite beze změny
                     ▼
              M2: TableSelection + RecordContract (A-2) ← V2.0.b zde
                     │
                     ▼
              M3: TableRenderState (A-3) ──┐
                     │                     ├─► M4: TableActionRunner (A-4) — nejtěžší
                     ▼                     │
              (paralelně B: Column) ───────┘
                     │
                     ▼
              M5: WithTable = tenký adapter (A-5) + Column typy → V2.1 DONE
```

- **M1 = go/no-go**: `TableDataset` zelený a **celá table suite beze změny** =
  důkaz, že extrakce nezměnila chování. Pokud vyžaduje úpravy testů, seam je
  špatný → zastavit.
- **M4 = nejtěžší** (`TableActionRunner`: modal flow + forms integrace) — kritická
  cesta A větve.
- **B (Column) neblokuje A** — běží paralelně, sjednotí se v M5.

## Testovací strategie

- **Golden master pro chování:** před extrakcí zafixovat stávající table feature
  suite jako referenční; po každé extrakci **musí zůstat zelená beze změny** (to je
  primární BC důkaz — stejný princip jako V2.0 M1).
- **Nové unit testy per collaborator:** `TableDataset`/`TableSelection`/
  `TableRenderState`/`TableActionRunner` testovatelné **bez** Livewire (headless
  exit kritérium). Shape coverage: prázdný dataset, cursor/simple paging, bulk
  napříč stránkami, sub-row/flatten/expansion kombinace.
- **Column typy:** unit per nový typ (Status/Money/Relation/Metric) + LSP kontrola
  (pozor na historické `ImageColumn::size()` LSP fatal [[column_partial_migration]]).
- **Matrix:** `composer test:table` + `test:sortable` (sortable staví na table);
  `Integration` (runtime/state/modal flow); `analyse` + `lint`; benchmark bez regrese.

## Rizika & mitigace

| Riziko | Mitigace |
|---|---|
| Rozřezání změní chování (regrese) | golden-master suite zelená beze změny po každém kroku (M1 gate) |
| PHPStan exploze u konkrétních collaborators | headless = čisté PHP bez Livewire magie (A.4) |
| Blast radius A-4 (modal/forms) | až po A-2/A-3; forms `InteractsWith*` traity nechat, jen přesunout orchestraci |
| Column přesuny rozbijí typy (LSP) | deprecation-first shim na base; LSP test per typ |
| Souběh A × B konflikty | různé soubory (WithTable vs Columns/) → nízká kolize; koordinovat jen sdílené `Concerns/` |
| V2.0.b × A-2 dvojitá práce | A-2 **je** nosič V2.0.b — dělat jednou (viz depends_on) |

## Definition of done (celé V2.1)

1. `WithTable` public API beze změny; tělo v collaborators; adapter tenký
   (cíl: výrazně pod 3213 ř., orchestrace v collaborators).
2. Collaborators testovatelné bez Livewire lifecyclu (headless exit, ADR 0017 C).
3. `Column` base zmenšen; `StatusColumn`/`MoneyColumn`/`RelationColumn`/
   `MetricColumn` existují, plně otestované; přesuny z base deprecation-first.
4. Golden-master table suite zelená beze změny; `analyse`/`lint` čisté; benchmark
   bez regrese.
5. V2.0.b (`RecordContract`) realizováno uvnitř A-2 (ne dvakrát).
6. Docs (`architecture/table.md` — nová collaborator struktura) + boost sync.
7. `v2-master-plan.md` V2.1 exit odškrtnut; #5/#6 označeny hotové; V2.3 odblokováno.
